# Video Compressor

Android-приложение: выбор видео из галереи (можно пачкой), сжатие на выбор — минимальный размер (360p), средний (720p), максимальный (исходное разрешение) — и сохранение в галерею (`Movies/Video Compressor`).

Kotlin, Jetpack Compose, Media3 Transformer. Сборка — GitHub Actions, APK в ветке `build`.
